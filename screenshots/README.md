# Evidence Guide

Useful public evidence for this project includes:

- sanitized tool-discovery screenshots
- Developer Mode / transport screenshots with private URLs removed
- listener logs with synthetic payloads
- architecture diagrams
- end-to-end test notes
- device-validation summary

Do not publish:

- private message content
- local network addresses that should remain private
- API keys or secrets
- personal identifiers
- live production tokens

The goal is to prove the integration path without exposing private infrastructure.
